How to Describe the Dimensions of a Handmade Item

Published 2026-11-01

TL;DR: Describe handmade item dimensions by naming the item first, then listing the relevant measurements in a clear order with units and a note on whether they are approximate or exact. Include the parts that affect fit, display, or use, keep the format easy to scan, and add variation notes only when they are true.

Intro

Describe handmade item dimensions by naming the item first, then listing clear measurements for each relevant part in the order buyers need them most, with units and a note on whether the size is approximate or exact. That keeps the listing useful instead of turning it into a tiny scavenger hunt.

How to describe handmade dimensions

Start with the measurements that matter for the item’s use. For a wearable, that might be width, length, and strap drop. For a mug, it might be height, diameter, and capacity if you know it. For wall decor, the overall size usually matters most, followed by anything that affects hanging or display.

Label each measurement plainly. Buyers should not have to decode craft-room shorthand like it is a secret level in a video game. Use words such as width, height, depth, diameter, or strap length when those parts matter.

Keep the wording easy to scan. Short lines, consistent units, and a steady order make the dimensions easy to compare across listings.

What to include in the measurement set

Handmade items often need more than one dimension, because one number rarely tells the whole story.

Include the overall size first, then add any part that affects fit, display, or use. That might mean:

  • body width and height for a bag or pouch
  • opening diameter and height for a mug or vessel
  • finished length and width for a wall hanging
  • strap, handle, or drop length when it changes how the item sits or hangs

If a dimension affects how a shopper uses the item, it belongs in the set. If it does not matter to the buyer, you can probably leave it out.

How to format the dimensions clearly

A clean pattern helps shoppers compare items fast. Use the same unit throughout, unless there is a strong reason not to. Keep punctuation consistent, and put the measurements in the same order every time.

A simple format looks like this:

Item name, then measurements: Width 12 in, height 9 in, depth 4 in.

Or, if bullets are easier to scan:

  • Width: 12 in
  • Height: 9 in
  • Depth: 4 in

If you use abbreviations, use them consistently. Pick either in or cm, not a casual mix that makes the line feel like it was assembled during a caffeine emergency.

If the measurements are exact, say so. If they are approximate, say that too, especially for handmade work where small differences may be part of the product.

Worked example: hypothetical handmade item listing copy

Here is a hypothetical listing sentence for a handmade tote bag:

Handmade tote bag, approximately 14 in wide by 15 in high, with a 10 in handle drop.

Or in bullet form:

  • Width: approximately 14 in
  • Height: approximately 15 in
  • Handle drop: approximately 10 in

That turns raw measurements into something a shopper can read without pausing to do mental math, which is always nice.

When to add notes about variation

Add a variation note only when it is true for the item. Handmade pieces can have slight differences from one item to another, but that note should support the dimensions, not weaken them.

A useful note is brief and specific, such as saying the item is handmade and may vary slightly from piece to piece. Keep the actual measurements in place so the buyer still has something concrete to judge size by.

Do not use variation language as a substitute for measurements. “It varies” is not a dimension. It is, at best, a shrug.

How this helps with Etsy listings

Clear dimensions help Etsy listings because buyers can judge fit, scale, and usability faster, which usually builds confidence before they click away or message you with the same question your description could have answered in ten seconds.
